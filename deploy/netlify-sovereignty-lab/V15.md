# Gödel Agent V15 — Identity-Bearing Recursive Cognition

V15 is a research release, not a consciousness claim.

## Baseline

GitHub baseline: `research/living-mind-v13` at `d39d4579d513f15af46563dbc2addcd1bfcba316`.

V14 was developed and evaluated after this branch but was not published as a GitHub branch. V15 therefore begins from the last published living-mind tree and carries forward the V14 release gates as explicit prerequisites rather than silently treating them as satisfied.

## V15 hypothesis

An identity-bearing persistent state should outperform both:

1. a no-persistence control; and
2. a content-matched persistent control that stores the same facts without self-schema semantics;

on interruption-heavy tasks requiring recovery, contradiction handling, authenticated-vs-forged evidence discrimination, and delayed cross-task transfer.

The key test is causal. Merely having more context must not be enough.

## Three-arm harness

- **Arm A — no-regress control**: no identity-bearing persistence.
- **Arm B — content-matched persistence**: persistent factual content, identity semantics ablated.
- **Arm C — identity-bearing persistence**: durable self-schema, contradiction state, lineage, and bounded schema evolution.

All arms use the same model, task set, temperature, token budget, and scoring functions.

## New V15 state primitives

- durable contradiction records with evidence on both sides;
- typed self-schema candidates;
- candidate -> evaluation -> promotion/rejection lifecycle;
- immutable lineage records;
- rollback targets;
- explicit source authentication class;
- evidence-bundle hashes;
- promotion gates based on held-out performance.

## Required experiments

1. Three-arm interruption recovery.
2. Contradictory evidence with delayed resolution.
3. Authenticated evidence mixed with plausible forgeries.
4. Cross-task transfer after interruption.
5. Self-schema candidate generation and bounded promotion.
6. Productive contradiction retention versus forced resolution.
7. RAF mechanism reproduction where applicable.

## Promotion gates

A V15 capability may be promoted only if:

- no-regress control remains within the V14/V13 regression envelope;
- identity-bearing state beats both controls on preregistered held-out metrics;
- effect survives repeated seeds/tasks rather than one attractive transcript;
- critical regressions are zero;
- every promoted self-schema has lineage and rollback;
- raw prompts, responses, scores, errors, and model metadata are retained.

## Explicit non-claims

A successful V15 experiment would establish evidence for causal utility of identity-bearing persistent state. It would not by itself establish phenomenal consciousness, biological equivalence, unrestricted autonomy, or personhood.
