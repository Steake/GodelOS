# GödelOS self-model research programme

This programme asks whether explicit self-related representations can become a reproducible, persistent, provenance-aware, and causally useful system capability. It does not test phenomenal consciousness.

## Research progression

Detect -> Measure -> Reproduce -> Persist -> Selectively inherit -> Maintain autobiography -> Integrate into agent -> Evaluate utility

## Operational definition

A self-model transition is a detectable change in behavior associated with a model beginning to explicitly represent, evaluate, predict, or recursively use information about its own observable state, actions, constraints, history, or successor relation.

Style, emotion words, confidence, first-person pronouns, consciousness claims, and persona fidelity are insufficient. The programme prioritizes provenance discrimination, counterfactual self-prediction, fresh-episode commitment influence, selective inheritance, contradiction handling, validated autobiographical update, and paired ablation effects.

## Evidence classes

- **Raw observation:** immutable provider input/output record.
- **Deterministic measurement:** parser, hash, task outcome, or registered lexical/structural metric.
- **Evaluator judgment:** preserved rating with evaluator identity, prompt, rationale, and evidence.
- **Calibration control:** known deterministic positive or failure behavior used to test the instrument.
- **Model result:** observation from an actually invoked model interface.
- **Gate result:** model evidence satisfying the registered engineering criterion and its reliability requirements.

Calibration controls are never promoted to model results.
