## Immediate engineering decision

Do not wire autobiographical identity state into the production agent yet. The sovereignty pilot establishes narrow, externally scaffolded persistence and critical integration, but recursion did not improve the task and the operational action was at ceiling. The next justified component is an authenticated typed successor-state service behind an experimental interface that:

1. stores the typed record unchanged;
2. creates a fresh provider episode;
3. records proposition-level inheritance decisions and separates rejection from revision/replacement;
4. validates and appends the successor record with parent and evidence hashes;
5. exports condition-blind evaluation bundles;
6. can be disabled or ablated per request.

Only replicated task utility that disappears under ablation should promote the successor service into general agent memory.
