# Recursive feedback research package

This directory is the publication surface for the GödelOS output-to-input study.
The package is a reconstruction manuscript and registered protocol, not a
results release.

Start here:

1. [Paper](PAPER.md): the argument, architecture audit, methods, and limits.
2. [Protocol](PROTOCOL.md): frozen conditions, outcomes, controls, exclusions,
   and archival requirements.
3. [Claims and provenance](CLAIMS_AND_PROVENANCE.md): what is implemented,
   intended, historically reported, hypothesized, or still unsupported.
4. [References](references.bib): machine-readable citation metadata.
5. [Experiment harness](../../../experiments/recursive_feedback/README.md):
   runner, trace schema, analyser, and offline tests.

## Current status

- Manuscript: complete for review.
- Protocol: complete for review; the version-one prompt bank is frozen and
  hashed, while immutable model IDs must still be selected before collection.
- Software: executable without external dependencies beyond a compatible model
  endpoint; offline tests make no network calls.
- Confirmatory traces: not collected.
- Early archival traces: not located in the repository audit.

This status language is intentional. It keeps a compelling research question
from acquiring results by rhetoric.
