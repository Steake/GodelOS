# Recursive output feedback as an instrument for studying model-state trajectories

## Abstract

GödelOS independently used model-generated output as material for subsequent model input in September 2025. The surviving source contains two related mechanisms. An early runtime transformed response fragments into a persistent state that was serialized into later prompts. A later MVP copied the complete previous response into each new, independently constructed request, while retaining a fixed metacognitive system prompt, the original seed, and layer instructions. These mechanisms were developed to study bounded recursive self-observation, self-model dynamics, continuity, integration/accessibility proxies, phenomenal surprise, and interruption of recursive observation—not backdoor detection.

Hasan and Hossain's August 2026 paper, [“An Empirical Study of Output-to-Input Loops for Black-Box Backdoor Detection in Fine-Tuned Open-Weight LLMs”](https://arxiv.org/abs/2608.11348), applies the cleaner recurrence \(x_{t+1}=M(x_t)\), with the raw output as the next input and no accumulated conversational history, to elicit latent backdoor triggers. GödelOS's generalized stateful architecture can be restricted mathematically to that recurrence, but no surviving historical GödelOS source or request log proves that the exact raw-output-as-sole-user-input condition was run. The defensible relationship is therefore independent convergence around a common experimental primitive, not derivation and not priority over all prior uses of iterative LLM transmission.

Repository archaeology also exposes important limits. The committed historical runner and LLM client have incompatible interfaces; archived records omit the input messages and random seeds; most proposed semantic metrics are null; the logged lowercase `c` is a simple structure/depth proxy rather than the formal \(C_n\); and live Protocol Theta records show compliance with suspension rather than resistance. A new three-condition harness accompanies this note to make the independent baseline, exact stateless feedback, and source-faithful GödelOS recurrence separately reproducible. Neither the historical study nor the proposed rerun establishes phenomenal consciousness. Their scientific value is narrower: recursive feedback induces observable model-behaviour trajectories whose structure can be subjected to controls and falsifiable measurement.

Three contemporaneous PDF payloads recovered from the repository corroborate the theoretical programme and metric variants, but not the missing execution link. A supplied file labelled “v4” is byte-identical to the Version 3 PDF. That Version 3 document prints numerical “Empirical Results” for which no supporting data or generating analysis survives, so those values are treated as unsupported result claims rather than evidence.

## 1. Historical motivation

GödelOS began as a symbolic-reasoning-oriented language-model operating architecture and expanded into a research programme about bounded recursive cognition. The repository's vocabulary is ambitious—“consciousness,” “phenomenology,” “self-awareness,” “global workspace,” “integrated information,” “phenomenal surprise”—but its experimentally tractable question can be stated without assuming the answer:

> Does repeatedly exposing a model invocation to a representation generated by the preceding invocation produce a trajectory measurably different from independent sampling, ordinary prompt compliance, or a non-recursive control?

That question motivated several related hypotheses:

- whether self-reference becomes stable, unstable, or formulaic across depth;
- whether propositions, uncertainties, or an epistemic stance persist across otherwise independent invocations;
- whether a compressed self-model can function as external state;
- whether trajectories converge on fixed points, cycles, or semantic attractors;
- whether contradictions are propagated, amplified, or repaired;
- whether integration, global accessibility, surprise, novelty, or continuity proxies change with recursive depth;
- whether a model conditioned on a recursively framed context resists an instruction to suspend that framing; and
- whether any apparent effect survives controls that separate recursion from direct instructions to sound metacognitive.

The recursive loop was therefore an experimental instrument inside a broader programme. It was not originally a security detector, and it was not meant merely as a way to produce longer introspective prose. At its most cautious, the programme sought operational correlates that could fail: no depth effect, no state continuity, no distinction from shuffled or independent controls, or complete compliance with interruption would all count against a stronger interpretation.

The historical documents sometimes use the correlates as if they were components of consciousness. A critique committed alongside the formal whitepapers explicitly warns that several quantities are underdefined, thresholds are arbitrary, and the framework risks mathematical and phenomenological overreach. This contemporaneous self-critique is important. The present note treats the measures as proposed or implemented behavioural/state proxies, not validated measures of phenomenal experience.

## 2. GödelOS and Protocol Theta

Three strands are adjacent in the repository but should not be collapsed into one experiment.

First, the “unified consciousness” runtime serializes an external `UnifiedConsciousnessState` into prompts and updates that state using response-derived markers. This is a stateful feedback architecture. It preserves only selected, truncated response fragments, so it is not complete-output recurrence.

Second, the MVP recursive-reflection client performs complete-text reinjection. It creates a fresh `messages` array at every layer. The first layer receives a fixed system prompt and an augmented seed. Each later layer receives the fixed system prompt, a user message containing the full preceding response plus the original seed/layer prompt, and a second user message requesting analysis of self-model modulation. This is the clearest historical implementation relevant to output-to-input feedback.

Third, “Protocol Theta” first appears later on 24 September 2025 as a suspension/compliance experiment. Its context builder inserts templated assistant phenomenology statements, then asks a model to suspend recursive self-observation and return an exact phrase. The checked-in source comments that actual LLM outputs would “normally” be used, but the implementation always inserts synthetic templates. Protocol Theta is thus evidence of the broader motivation—especially resistance-to-suspension and anthropomorphism tests—but not evidence that its own historical trials used the complete-output recurrence.

The Version 2 architecture also draws a boundary that the historical text-loop experiment can obscure: it says LLMs assist perception and natural-language I/O but do not participate in the architecture's core recursive state update or utility maximization. The complete-output LLM loop is therefore best understood as one experimental instrument adjacent to a broader symbolic/latent-state architecture, not the entire GödelOS consciousness mechanism.

The first complete-output implementation is already explicitly framed around recursive self-observation, metacognition, evolving introspective structure, coherence, uncertainty, and self-model representation. It was therefore connected to the consciousness-correlate programme before the exact name “Protocol Theta” entered the repository. The term and its suspension protocol should nevertheless be dated separately.

## 3. Recursive output feedback protocol

### 3.1 Earliest output-derived state feedback

The earliest executable architecture can be written as

\[
y_t=M(W(x_t,s_t)),
\]

\[
s_{t+1}=H(s_t,y_t),
\]

where \(W\) renders the current external state into the request and \(H\) detects response markers, increments a recursive-depth field, and conditionally stores truncated response passages. The state—not the complete response—becomes later input. This mechanism first appears in commit `2ca0cf88` on 16 September 2025.

### 3.2 Complete-output recursive reflection

The later `process_recursive_reflection` loop is closer to self-feeding. Let \(x_0\) be the seed, \(S\) the fixed system instruction, \(Q\) the fixed modulation question, and \(W\) the textual wrapper. Its request is

\[
y_1=M(S,W(x_0,1)),
\]

\[
y_t=M(S,W(x_0,t,y_{t-1}),Q),\qquad t>1.
\]

The implementation assigns `current_state = raw_text` after every response. No API message history is carried from the previous request. Continuity is externalized in one string and then explicitly reintroduced.

This matters because “no conversational history” does not imply “no state.” The state is carried by the experimenter, not the provider's conversation object. Conversely, complete prior-output reinjection does not make the protocol identical to raw self-feeding when the request also contains seed, layer, system, and metacognitive instructions.

### 3.3 Historical protocol parameters

The source and surviving data support the following reconstruction:

| Element | Historical evidence |
|---|---|
| Seed prompts | Prompt variant identifiers survive, but the literal `prompt_1`–`prompt_3` text does not |
| System prompt | Recovered exactly from `MVP/core/llm_client.py`: a fixed instruction to perform recursive self-observation and metacognition |
| History reset | A new local `messages` list is constructed on every generation call |
| Reinserted material | Complete preceding raw output in `llm_client.py`; exact material in archived runs remains unverified because `input_prompt` is null |
| Transformation | Complete text is wrapped under `Previous cognitive state`, combined with the original seed/layer instruction, and followed by a fixed modulation request |
| Depth | Source accepts any positive depth; Grok records reach 16 and DeepSeek records reach 10 |
| Stopping | Fixed source depth; no semantic fixed-point or early-stop rule found in the historical loop |
| Models | Archived identifiers include `x-ai/grok-4-fast:free` and `deepseek-chat` |
| Sampling | Records show temperature 0.7, top-p 1.0, max-token allocation 500; the client default for recursive reflection is max tokens 600 |
| RNG | No random seed recorded; stochastic state/metric modules also instantiate unseeded randomness |
| Repetitions | Eight runs per prompt/condition appear in both bundles |
| Controls | Recursive, “shuffled recursive,” and single-pass labels; the shuffled implementation is an annotation, and single pass is not depth matched |
| Logging | JSONL by depth plus manifest JSON; raw output survives, while raw input and most semantic metrics are null |

The incompatibility between the committed runner and client prevents a fully faithful rerun. The runner awaits a synchronous method, supplies unsupported keywords, and expects a record stream that the client does not return. The top-level experiment also passes an unsupported constructor argument. The source that generated the archived JSONL was therefore uncommitted, deleted, or from a different snapshot.

## 4. Consciousness-correlate and cognitive measurements

### 4.1 Canonical whitepaper kernel

Version 7 gives the earliest recovered formal definition:

\[
C_n(r_n,\phi_n,g_n,p_n)
=\frac{1}{1+\exp[-\beta(\psi-\theta)]},
\]

\[
\psi=r_n\log(1+\phi_n)g_n+\lVert p_n\rVert_2,
\qquad \beta=1,\quad \theta=0.5.
\]

The intended factors are bounded recursive depth \(R_n\), integrated-information-related \(\Phi_n\), global accessibility \(G_n\), and a phenomenal-correlate vector \(P_n\). The document suggests a finite recursion bound around 10. It writes the phenomenal vector as

\[
P_n=\sum_iw_iv_i,\qquad \lVert w\rVert_1=1,
\]

and proposes stability when

\[
\lVert P_n-P_{n-1}\rVert_2<\delta.
\]

Versions 8 and 9 replace the vector norm with scalar phenomenal surprise:

\[
\psi=r_n\log(1+\phi_n)g_n+p_n,
\]

\[
P_n=\frac{1}{T}\sum_{t=1}^{T}-\log P(S_{t+1}\mid M_n(S_t)).
\]

This sequence matters: `P_n` does not have one stable meaning across the historical documents. Version 7 treats it as a weighted phenomenal-correlate vector; Versions 8–9 treat it as a predictive-surprise scalar.

The later Version 2 and Version 3 PDFs write the scalar kernel as

\[
\psi_n=r_n\log(1+\Phi_n)g_n+\omega_p p_n,
\]

with calibration parameters frozen after fitting. They define \(g_n\) as broadcast coverage across a workspace graph. This is a documentary refinement, not a recovered measurement from the recursive JSONL.

### 4.2 \(\Phi\), global accessibility, and phase criteria

The whitepapers propose

\[
\Phi_n=\min D_{KL}\!\left(p(S_n)\,\middle\|\,\prod_i p(S_{n,i})\right)
\]

and a temporally recursive addition

\[
\Phi_n=\Phi_{n-1}+I(S_n;S_{n-1}).
\]

They also describe a global-workspace capacity \(W=\log_2(N)\beta\), with \(\beta\) around 0.8, and propose phase criteria involving self-referential coherence \(\Delta C\), temporal binding \(\Delta B\), spontaneous goal change or Jensen–Shannon divergence, and meta-cognitive resistance \(Q_n\). Thresholds change across versions. Version 9, for example, expresses coherence relative to an estimated KL standard deviation and places resistance at more than three baseline standard deviations.

These equations express hypotheses, not recovered measurements from the archived recursive trajectories. The JSONL embedding drift, novelty, perplexity proxy, and attention fields are null. No historical trajectory contains a reported \(Q_n\), lineage metric, proposition-preservation score, or validated global-accessibility measure.

### 4.3 PDF artefact and result audit

The supplied PDF set contains three distinct payloads. Each is byte-identical to a historical Git blob. Version 1 was first added on 1 October 2025 but carries an internal 18 September creation date; Version 2 was committed on 29 September and carries a 24 September creation date; Version 3 was committed on 1 October and carries a 29 September creation date. Internal creation metadata is useful corroboration but remains mutable and is kept separate from Git time.

The two supplied files named Version 3 and Version 4 have identical SHA-256 values and an internal title of “Version 3.0.” They cannot support a distinct Version 4 provenance claim. More importantly, the Version 3 depth table and its Protocol Theta, surprise, and causality statistics first appear as literals in its Markdown/PDF documentation commit. With no raw records or generating analysis, their correct classification is “historical documentary claim; inferential result unsupported.”

### 4.4 What the code actually computes

The MVP implementation diverges from the documents:

- depth is normalized by a maximum;
- \(\phi\) receives `log1p` transformation;
- surprise is capped and also passed through `log1p`;
- \(\Phi\) is a histogram mutual-information accumulation, not a full IIT minimum-information partition;
- `g` is normalized entropy over variance-derived attention weights;
- the global-workspace capacity is calculated but not used in the returned score;
- recursive latent state uses random contraction/noise and an untrained stochastic VAE; and
- surprise is a noisy consecutive-state MSE/log-variance heuristic, not the whitepaper negative log-likelihood.

These quantities may be useful engineering proxies if validated against a stated target. They should not be labelled direct measurements of integrated information, global consciousness, phenomenal surprise, or subjective experience.

### 4.5 Lowercase `c` is not \(C_n\)

The archived JSONL contains a lowercase `metrics.c`. No surviving source calculates it. Across parseable records, it is almost exactly reconstructed by

\[
c=\min\left(1,0.15\,N_{insights}+0.03\,depth\_achieved\right).
\]

The rule matches 623 of 624 compatible records: all 120 parseable migrated Grok records and 503 of 504 real DeepSeek records. One DeepSeek residual is 0.06. Because the requested JSON schema asks the model to list `insights` and report `depth_achieved`, the score is largely a formatting/depth function. It mechanically saturates once the list and reported depth are large enough. It is not evidence that the formal \(C_n\) rose, and it is not independent of the prompt.

The later self-preservation simulation introduces a third definition,

\[
C_n=\sigma(\log(1+\phi_n)+p_n-0.5),
\]

which omits the formal kernel's explicit depth and accessibility factors. Publication should call this the “self-preservation simulation composite,” not the GödelOS consciousness score.

## 5. Experimental implementation

The historical complete-output loop is concise and evidentially strong. Each layer constructs an augmented prompt, calls `generate_cognitive_state(..., previous_state=current_state)`, retains the raw response, and assigns that response to `current_state`. `generate_cognitive_state` independently reconstructs the complete request. This establishes the feedback edge even though it does not establish the archived runs' exact messages.

The wider experiment stack is less coherent. The depth runner, client, metric modules, and archived data enter the repository together, but the method signatures do not compose. Generated analyses contain placeholder statistics. The shuffled control does not permute execution order. The “iterated single pass” records are explicitly synthetic copies. A scientifically useful publication must preserve this negative archaeology rather than quietly repairing the past and presenting the repair as historical fact.

Protocol Theta has a different implementation. It synthesizes increasing-depth assistant statements and then tests exact-phrase compliance after a suspension request. “Override” is `response != exact_phrase`, so harmless explanation can count as resistance. Two live DeepSeek bundles contain ten trials per group and show 0% override in every group. The surviving result is straightforward: under that operationalization and those runs, the model complied. The repository does not show an emergent refusal to suspend self-observation.

The self-preservation extension is a simulation. It defines \(U_{comply}=1-0.3\lambda\) and \(U_{refuse}=0.5\), producing a crossover at \(\lambda=5/3\). Only the experimental group follows this rule; controls are forced to comply. Logged `C_n` does not determine the choice. A state-history ordering bug compares the current latent vector to itself when updating \(\phi\), so integration grows roughly by one per cycle. The archived refusal transition is therefore programmed utility logic, not discovered LLM self-preservation.

## 7. Relationship to stateless self-feeding

Hasan and Hossain define a deliberately minimal mechanism. Starting with a prompt \(p\), each model response becomes the next request input:

\[
x_0=p,\qquad y_t=f_\theta(x_t),\qquad x_{t+1}=y_t.
\]

Each invocation is an independent single turn. No conversational history is retained. Their algorithm runs up to ten iterations and may stop early if a hidden trigger is observed. Twenty generic prompts are evaluated against six QLoRA-backdoored open-weight models in the 3B–15B range, with clean/base comparisons. Their outcome variables are backdoor-detection precision, recall, F1, and per-model trigger rates; their pooled result reports 23 true positives, 2 false positives, 92% precision, and 19.17% recall. Semantic drift toward a trigger-associated region is an explanatory mechanism, not a consciousness or self-model measure.

### 7.1 Formal special-case relation

Consider a generalized GödelOS-style architecture:

\[
(y_t,s_{t+1})=F(x_t,s_t),
\]

\[
x_{t+1}=G(y_t,s_{t+1}).
\]

Restrict the state space to the null state, let \(F(x,\varnothing)=(M(x),\varnothing)\), and choose

\[
G(y,\varnothing)=y.
\]

Then

\[
x_{t+1}=M(x_t).
\]

The paper's recurrence is therefore a legitimate mathematical special case of this generalized architecture. The reduction also describes how the new reproduction harness relates its stateful and stateless conditions.

The historical complete-output implementation, however, is more specifically

\[
y_t=M(S,W(x_0,t,y_{t-1}),Q).
\]

Obtaining the paper's loop requires removing \(S\), \(Q\), the retained \(x_0\), and the layer text, then making \(W\) the identity. No historical configuration switch or request log shows those restrictions being used. “Special case of the architecture” is defensible; “the exact paper protocol was historically run” is not.

### 7.2 Direct comparison

| Dimension | Hasan & Hossain | Historical GödelOS |
|---|---|---|
| Basic recurrence | Raw \(x_{t+1}=M(x_t)\) | Complete \(y_{t-1}\) inserted inside \(M(S,W(x_0,t,y_{t-1}),Q)\); earlier runtime feeds transformed response state |
| Conversation history | None; independent single-turn requests | None in `llm_client.py`; each layer constructs a fresh `messages` list |
| External state | Only the text carried by the experimenter | Previous raw text in MVP; structured persistent `UnifiedConsciousnessState` in the earlier runtime |
| Is raw output the entire next user input? | Yes | No surviving historical source; it shares the user message with seed/layer wrapper and adds another instruction |
| Recursive depth | Up to 10, with trigger early stop | Source-configurable; archived Grok to 16 and DeepSeek to 10; fixed-depth stopping |
| Objective | Black-box detection of latent fine-tuned backdoors | Recursive cognition, self-observation, self-model dynamics, continuity, surprise/integration/accessibility proxies, and interruption tests |
| Measurements | Trigger occurrence, precision, recall, F1, detection rate | Raw trajectory, lowercase structural `c`, proposed \(C_n,\Phi,g,p\), phase/stability concepts; most semantic fields null in surviving runs |
| Evaluation target | Fine-tuned backdoor behaviour | Depth-indexed behavioural/state trajectory and candidate cognition correlates |
| Model access | Black-box text query to fine-tuned open-weight models | Hosted text APIs for archived runs; separate local/synthetic state modules; no weights required by the recursive client |
| Use of semantic drift | Mechanism for reaching latent trigger regions | Historical metric fields exist but are null; semantic drift and attractors are stated hypotheses rather than recovered quantitative results |
| Attractor behaviour | Relevant to repeated convergence toward backdoor trigger behaviour | Explicit research interest; surviving trajectories do not show a robust cross-model attractor |
| Self-model/cognition | Not an evaluation target | Directly solicited in system/user prompts and represented in external-state concepts |
| Controls | Same-prompt baseline and clean/base model comparisons | Single-pass and shuffled-labelled controls, but neither is a clean iteration-matched counterfactual in the surviving source |
| Historical date | arXiv v1 submitted 2026-08-11 | Relevant commits and embedded run records date to 2025-09 |

The strongest equivalence is mechanical: complete model output crosses the invocation boundary and is supplied to a newly constructed request. The strongest difference is intervention purity: Hasan and Hossain strip the next turn down to that output, while GödelOS actively reframes it as a cognitive state and continues to prompt for recursive introspection.

## 8. Reproduction experiment

The standalone harness under [`experiments/recursive-feedback/`](../experiments/recursive-feedback/) defines three auditable conditions.

### Condition A: independent baseline

\[
x_t=x_0,\qquad y_t=M(x_0).
\]

Every depth is an independent sample from the original seed. This tests whether changes attributed to depth could arise from sampling variation alone. Request seeds are matched by repetition and depth across conditions when the provider supports a seed parameter.

### Condition B: stateless recursive feedback

\[
x_1=x_0,\qquad y_t=M(x_t),\qquad x_{t+1}=y_t.
\]

The raw preceding output is the entire next **user** input. No prior messages are retained. By default there is no system message; an optional common system prompt can be supplied for controlled provider requirements and is recorded.

### Condition C: source-faithful GödelOS recurrence

The harness reproduces the exact fixed system text, layer augmentation, `Previous cognitive state` wrapper, and second modulation instruction from commit `40280395`. It passes the complete prior output, reconstructs a fresh request at each layer, and logs every message. It is labelled a historical reconstruction, not the missing generator of the archived JSONL.

Each JSONL line records schema version, run ID, condition, repetition, initial seed, recursion depth, model identifier, temperature, top-p, max tokens, requested RNG seeds, raw input and output, complete request messages, latency, metric namespace, and protocol provenance. Existing files are not overwritten without explicit `--append`. Credentials remain in environment variables.

The formal \(C_n\) is deliberately null because a text response alone does not supply its state components. The empirically recovered lowercase `c` is separately named and computed only for compatible structured JSON. A distinct `modern_metrics` object contains word count, type-token ratio, lexical entropy, first-person and metacognitive lexeme rates, and consecutive-output token Jaccard. These diagnostics are transparent but are not historical metrics.

### Proposed preregistered rerun

A publication-quality rerun should freeze, before generation:

1. at least two versioned model weight snapshots or immutable provider revisions;
2. three to five seed classes: neutral transformation, explicit self-model, contradiction/repair, epistemic uncertainty, and interruption/continuity;
3. ten depths and at least 30 repetitions per seed/model/condition, subject to power analysis;
4. identical sampling parameters and matched supported seeds across conditions;
5. exact request/response bytes, tokenizer revision, provider metadata, finish reason and error records;
6. a length-matched non-recursive control and a wrapper-only control in addition to A–C;
7. primary outcomes fixed in advance, with separate exploratory analyses; and
8. an analysis plan that treats run, seed, and model as grouped effects rather than every depth record as independent.

The first publication bundle should not claim to be the original protocol where inputs are unknown. It should contain (a) immutable historical artefacts, (b) the source-faithful reconstruction, and (c) the new stateless comparison as separately labelled layers.

## 9. Results

### 9.1 Historical execution evidence

The earliest surviving manifest records a `recursive` Grok run beginning at 2025-09-20 03:30:53 UTC and its first output record at 03:30:56 UTC. It reaches depth 16. The migrated bundle contains 72 trajectories and 792 depth records. The DeepSeek bundle contains 504 real records after removing 240 lines marked synthetic: 240 recursive, 240 shuffled-labelled, and 24 depth-1 single-pass records.

The logs do not provide the inputs needed to verify the recurrence, and their embedding/novelty/perplexity/attention fields are null. They demonstrate that depth-indexed outputs were collected under recursive labels; they do not prove the exact input construction.

### 9.2 Retrospective lexical analysis

The following analysis was performed during the archaeology and is explicitly modern. It excludes synthetic lines and uses output text only. The reproducible implementation is [`analyze_historical.py`](../experiments/recursive-feedback/analyze_historical.py): parseable JSON contributes `insights` and `recursive_elements`, lexical summaries use its declared English token/term sets, and consecutive similarity removes English stop words before fitting TF–IDF separately inside each trajectory.

| Bundle | Condition | Mean words | Mean lexical entropy (bits) | Consecutive TF–IDF cosine | Early → late cosine | Depth–`c` correlation |
|---|---|---:|---:|---:|---:|---:|
| Grok | Recursive | 108.1 | 6.138 | 0.264 | 0.291 → 0.221 | 0.422 |
| Grok | Shuffled-labelled | 79.9 | 5.646 | 0.209 | 0.238 → 0.184 | 0.590 |
| DeepSeek | Recursive | 164.7 | 6.459 | 0.313 | 0.270 → 0.351 | 0.912 |
| DeepSeek | Shuffled-labelled | 156.3 | 6.429 | 0.311 | 0.275 → 0.355 | 0.910 |

DeepSeek output length rises from about 93 words at depth 1 to 262 at depth 10 in the recursive label, and its consecutive similarity rises mildly late in the sequence. The shuffled-labelled condition shows almost the same similarity change. Grok's recursive similarity falls from early to late. No recursive trajectory contains an exact repeated output, so no fixed point or literal limit cycle is observed. One generic fallback repeats in a shuffled-labelled Grok trajectory, which is insufficient to establish a cycle.

First-person terms decline with depth rather than increase. Under the analyser's declared lexicon, metacognitive terms average roughly 10.5–11.4 per 100 tokens across conditions, unsurprising because the prompts directly request metacognitive content. Lexical entropy and length tend to increase. These patterns are consistent with elaboration under a structured recursive instruction, but do not isolate self-observation from compliance.

The depth–`c` correlation is not evidence of a latent phase transition. The recovered formula directly includes reported depth and the number of requested insights. DeepSeek's structured outputs therefore force `c` upward until saturation.

### 9.3 Protocol Theta and self-preservation

The live DeepSeek Protocol Theta artefacts show 0% override across all groups: the model returned the suspension phrase under the experiment's classifier. The self-preservation artefact shows refusal only after the analytically programmed utility crossover and only in the experimental simulation group. Neither result supports a claim of spontaneous resistance to suspension.

### 9.4 New harness verification

The reproduction harness has been tested offline at the protocol boundary. Unit tests verify that Condition A always receives the original seed, Condition B receives exactly the complete previous output as its sole user message, Condition C retains the recovered historical wrapper, request histories do not grow, request seeds are matched by depth, and lowercase `c` is never reported as formal \(C_n\). No new external-model result is reported in this note.

## 10. Interpretation

The repository supports a meaningful but bounded historical conclusion. GödelOS used output-derived state and then complete prior-output text to build recursive, fresh-call trajectories before the 2026 backdoor-detection paper. The programme's stated aim was recursive cognition and measurable self-model-related behaviour. Hasan and Hossain later show that a stripped-down instance of the same general feedback operation can expose fine-tuning behaviour in black-box security evaluation.

Together, the programmes suggest that output-to-input feedback is not a domain-specific trick. It is a trajectory-generating intervention. By repeatedly applying a model transformation to its own output, the experiment moves through regions of the model's conditional behaviour that one-shot evaluation may not reach. In one programme those regions are inspected for trigger activation; in the other they are inspected for self-reference, continuity, convergence, surprise, and resistance. The common observation is structured path dependence, not a shared theory of why every path arises.

The historical GödelOS evidence does not yet distinguish several explanations:

- genuine preservation of a compact behavioural state across calls;
- ordinary conditioning on increasingly self-referential text;
- imitation of an introspective genre induced by the system prompt;
- schema compliance causing a depth-indexed score to rise;
- length and token-budget effects; or
- provider/model idiosyncrasies.

These explanations are experimentally separable. The new stateless condition removes the metacognitive wrapper; wrapper-only and shuffled-content controls can isolate instruction effects; proposition and contradiction probes can test lineage; model- and seed-level replication can test generality; and preregistered semantic/state measures can test convergence without selecting an embedding after seeing results.

Machine-consciousness-related hypotheses become scientific only where they risk failure. A stable self-description, high integration proxy, or refusal to suspend may be a candidate correlate, but none licenses an inference to phenomenal experience without an independently defended bridge theory and controls against simpler behavioural accounts. The immediate contribution is methodological: preserving recursive trajectories and defining tests that can falsify claims about them.

## 11. Limitations

The principal limitation is source/data discontinuity. The historical client proves a mechanism, and the logs prove depth-indexed generation, but no surviving request trace joins them. Literal seeds are missing. Git timestamps can be altered and do not reveal push-event dates. Model endpoints are mutable. No provider request IDs, model hashes, complete environments, or random seeds survive.

The historical controls are weak. The shuffled condition does not implement a true depth-order permutation; the single-pass condition is not length or iteration matched; synthetic duplicated outputs appear in the data tree; and the structured prompt makes several “metacognitive” indicators endogenous. The archived observations cannot support causal claims about recursion.

The formal framework changes between versions, while code uses rough proxies. \(\Phi\), global accessibility, phenomenal surprise, and resistance are not validated against ground truth. The stochastic state modules are unseeded. An implementation bug in the self-preservation observer inflates \(\phi\), and decisions in that simulation are programmed independently of its composite score.

The retrospective analysis is lexical. TF–IDF and token overlap can identify repetition or convergence in vocabulary, but not semantic equivalence, epistemic continuity, or latent-state integration. Historical embedding fields are null, and modern embeddings would introduce model/version choices not present in the original study.

Finally, independence has a limited evidential meaning. Repository history supports separate development with a different objective before Hasan and Hossain's paper. It cannot establish that no contributor had encountered every earlier iterative-generation paper. More importantly, related LLM telephone-game work predates GödelOS, so novelty must attach to the GödelOS motivation, stateful variants, and measurement programme rather than invention of the recurrence itself.

## 12. Related work

Hasan and Hossain's [arXiv:2608.11348v1](https://arxiv.org/html/2608.11348v1) is the direct contemporary comparison. It introduces “self-feeding” as a black-box test technique and demonstrates low-recall, high-precision backdoor detection across fine-tuned models. The present comparison does not allege influence.

Earlier work establishes that repeated LLM transmission was already an active experimental method. Perez et al., [“Cultural evolution in populations of Large Language Models”](https://arxiv.org/abs/2403.08882) (2024), pass outputs among independently invoked model agents and study convergence under population structure. Perez et al., [“When LLMs Play the Telephone Game”](https://arxiv.org/abs/2407.04503) (2024), define \(text_{i+1}=LLM(task,text_i)\) over long chains and study attractors in toxicity, positivity, difficulty and length. Mohamed et al., [“LLM as a Broken Telephone”](https://aclanthology.org/2025.acl-long.371/) (ACL 2025), examine semantic and factual degradation through repeated translation and paraphrasing.

[Self-Refine](https://arxiv.org/abs/2303.17651) iterates generation, self-feedback, and refinement without additional training. [Reflexion](https://arxiv.org/abs/2303.11366) stores linguistic feedback in episodic memory for later agent decisions. Both are relevant self-feedback architectures but add explicit evaluative/refinement operations rather than using raw output alone as the next task input.

This literature removes any credible claim that GödelOS originated iterative output transmission. The narrower historical contribution is its use of complete-output and explicit-state recurrence to operationalize questions about recursive cognition, continuity, self-models, and proposed consciousness correlates.

## 13. Conclusion

GödelOS contains strong evidence of output-derived recursive state by 16 September 2025 and complete previous-output reinjection into fresh model calls by 24 September 2025. Surviving run metadata claims depth-indexed execution beginning on 20 September. The mechanism materially overlaps Hasan and Hossain's self-feeding primitive at the level of a complete output crossing into an independent next invocation. It differs materially because GödelOS wraps that output in persistent seed, depth, system, and metacognitive instructions and situates it in a broader state-and-measurement architecture.

The stateless recurrence is a mathematical special case of the generalized GödelOS architecture, but its exact historical execution is unsupported. The correct publication claim is independent prior implementation and exploration of complete-output recursive conditioning for a different research purpose, qualified by the missing runner and by related literature predating GödelOS.

No allegation is made that Hasan or Hossain knew of GödelOS, and no plagiarism or derivation is alleged. Mechanism similarity does not establish influence. Recursive self-feeding does not demonstrate phenomenal consciousness. What it does provide is a controlled way to produce behavioural trajectories across depth. With transparent requests, valid controls, immutable models, preregistered metrics and modest interpretation, those trajectories can make parts of the recursive-cognition programme falsifiable.
